# Architectural decision records

llama-launcher's decision records live in Knowledge as `adr-NNNN` Notes under the `decisions` Note.

- `capcom know show decisions`: the list of records
- `capcom know show "ADR-0010"`: one record, its Status line and its reading order
- A new record takes the next number (`adr-0017`) and the shape the existing records give; edit
  records in place under `.capcom/knowledge/decisions/`.
