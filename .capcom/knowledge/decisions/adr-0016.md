---
title: api_key_cmd runs only from a config the user owns
---

Status: Accepted.

On unix, `api_key_cmd` runs only when the config file is owned by the current uid and not group-
or world-writable; otherwise the load stops naming `chmod 600`. Read `adr-0016-decision` for the
gate and its scope, then `adr-0016-why` for the rejected argv split, then
`adr-0016-consequences`.
