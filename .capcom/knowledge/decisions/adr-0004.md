---
title: "`auto_unload` is one rule covering both same-server and cross-server cases"
---

Status: Accepted.

A single `auto_unload` flag unloads every Model the activated Profile does not load, on the same
LLM Server and on any other one still running. Read `adr-0004-decision` for the rule, then
`adr-0004-why` for the rejected two-flag split, then `adr-0004-consequences` for its interplay
with `auto_stop_server` and `llamacpp`.
