---
title: Profile activation is idempotent by name within an address slot
---

Status: Accepted.

Loading a Profile whose Model is already loaded at its address does nothing, but a notice names any
parameter drift and points to `--restart`. Read `adr-0007-decision` for the rule, then
`adr-0007-why` for the two rejected alternatives, then `adr-0007-consequences` for the live probe,
which parameters are diffed, and the per-address scope.
