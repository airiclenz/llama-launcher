---
title: "The repo owns its release pipeline: cmd/release publishes prebuilt archives and a prebuilt Homebrew formula"
---

Status: Accepted.

A llama-launcher release is cut from a clone of this repository: the Go dev tool `cmd/release`
builds prebuilt darwin/linux archives, gates on green CI and publishes the GitHub release and a
prebuilt-binary Homebrew formula, converging when rerun; CI only tags the `VERSION` bump. Read
`adr-0017-decision` for the verbs, the channels and the calls ratified on 2026-10-12, then
`adr-0017-why` for what it replaced and the options turned down, then `adr-0017-consequences`.
