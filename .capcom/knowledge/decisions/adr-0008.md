---
title: Remote control runs through a separate MCP adapter, not a listener in the CLI
---

Status: Accepted.

Remote control of the host runs through a separate `llama-launcher-mcp` binary that shells out to
the CLI; the CLI itself stays listener-free. Read `adr-0008-decision` for the rule, then
`adr-0008-router` for why it does not contradict ADR-0002, then `adr-0008-shellout`, then
`adr-0008-trust` for the IP-allowlist trust model and input gate, then `adr-0008-consequences`.
