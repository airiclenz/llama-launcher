---
title: A Splash Model must already be installed; the launcher never downloads one
---

Status: Accepted; amended 2026-10-29.

A Splash Profile's Model must already be installed in the Hugging Face cache; the launcher refuses
an uninstalled one with the install command and never downloads it. Read `adr-0014-decision` for
the rule and what counts as installed, then `adr-0014-why` for the invisible download and the
two subordinate choices, then `adr-0014-consequences`. The decision and why Notes carry a dated amendment on the install marker.
