---
title: On-demand Model serving runs through a separate Gateway binary, not the CLI
---

Status: Accepted.

On-demand Model serving runs through an optional, resident Gateway binary that activates Profiles
through the library facade and proxies OpenAI-compatible traffic; the CLI stays listener-free.
Decided 2026-08-05, not yet built. Read `adr-0013-decision` for the rule, then
`adr-0013-exception` for why it is a scoped exception to ADR-0002, then `adr-0013-standalone`,
then `adr-0013-behavior`, then `adr-0013-library`, then `adr-0013-consequences`, then
`adr-0013-brief` for the go/no-go decision brief.
