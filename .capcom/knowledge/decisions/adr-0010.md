---
title: A Starting LLM Server is visible and stoppable; only `--restart` displaces it
superseded-by: [adr-0015]
---

Status: Accepted; amended 2026-09-24 and superseded in part 2026-09-24.

A Starting LLM Server is a first-class running instance: discovery reports it, an explicit stop
and the `auto_stop_server` sweep stop it, and only `--restart` displaces it. This still holds;
ADR-0015 amends the Starting definition for Splash (a process up with its address still unbound),
and a 401/403 answer at a configured address is no longer covered by its identification rule.
Read `adr-0010-decision` for the rule, then `adr-0010-why`, then `adr-0010-consequences`, then
`adr-0010-amend-0924` for Splash, then `adr-0010-partial-0924` for the 401/403 case.
