---
title: A Profile must name its LLM Server explicitly
---

Status: Accepted.

Every Profile names its LLM Server with `server:`; the `defaults.server` fallback warns and is on
its way out. Read `adr-0005-decision` for the rule and the deprecation path, then `adr-0005-why`
for why the LLM Server is part of a Profile's identity, then `adr-0005-consequences`.
