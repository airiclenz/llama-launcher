---
title: Stop is unconditional, regardless of who started the LLM Server
---

Status: Accepted; amended 2026-09-24.

Any stop terminates the LLM Server at the instance's address, whoever started it; there is no
managed/external distinction. Read `adr-0001-decision` for the rule and Ollama's address-scoped
stop, then `adr-0001-why` for the retired `managed` flag, then `adr-0001-consequences`, then
`adr-0001-amend-0924` for servers that refuse every backend's `api_key`.
