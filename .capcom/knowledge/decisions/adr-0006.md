---
title: LLM Server instances are keyed by `host:port`, not by type
---

Status: Accepted.

A running LLM Server is identified by the `host:port` it binds, not by its type, so any number of
instances can run side by side. Read `adr-0006-decision` for the rule, then `adr-0006-why`, then
`adr-0006-state` for the per-instance state files, then `adr-0006-conflicts` for two Profiles on
one address, then `adr-0006-consequences`.
