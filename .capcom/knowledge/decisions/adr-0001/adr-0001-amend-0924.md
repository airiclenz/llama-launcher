---
title: "ADR-0001 amendment of 2026-09-24: a server refusing every backend's api_key is found as AuthFailed, and an explicit stop signals it"
---

> **Amended 2026-09-24.** A server that answers every configured backend with 401/403 — it refuses the configured `api_key`, so no backend can identify it — used to be invisible, and `stop` against it refused with "no server running". It is now discovered as one `AuthFailed` instance per address (`Backend ""`), and an explicit `stop` signals its listener (no stop hook runs, since no backend identified it). The `auto_stop_server` sweep is the one carve-out: it skips such servers, so only an explicit stop signals them. `load` and `unload` against one refuse with the "check api_key" error. See the matching amendment to ADR-0010.
